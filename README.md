# LockInLearn

Aplikasi mobile berbasis **Flutter** untuk mendukung proses belajar dan produktivitas (*Lock In*).

## ```Saat ini proyek berada dalam tahap inisialisasi awal.```

---

## 📌 Deskripsi

**LockInLearn** adalah proyek aplikasi Flutter yang dirancang untuk platform multi-target (Android, iOS, Web, macOS, Linux). <br>

---

## 🚀 Memulai (Getting Started)

### Prasyarat

Pastikan Anda sudah menginstal:

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (versi SDK Dart `^3.13.3` atau kompatibel)
- Android Studio / VS Code dengan ekstensi Flutter & Dart
- Emulator Android / Simulator iOS / Chrome (untuk web) atau perangkat fisik

### Instalasi & Menjalankan Aplikasi

1. **Clone repositori:**

   ```bash
   git clone https://github.com/zakkizakwan/LockInLearn.git
   ```

2. **Unduh dependensi:**

   ```bash
   flutter pub get
   ```

3. **Jalankan aplikasi:**

   ```bash
   flutter run
   ```
